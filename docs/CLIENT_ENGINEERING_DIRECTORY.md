CLIENT ENGINEERING DIRECTORY: THE ELITE STANDARD
Este manual define o padrão de construção para projetos de terceiros sob o selo Joestar Mídia. Aqui, a identidade visual é adaptável à marca do cliente, mas a Engenharia de Prestígio é inegociável.

1) O PILAR DA ROBUSTEZ (STACK 2026)
Todo projeto de cliente deve ser construído sobre a fundação mais avançada disponível para garantir longevidade e segurança.

Framework: Next.js 15 (App Router) + React 19.

Linguagem: TypeScript rigoroso (Strict Mode: ON).

Estilização: Tailwind CSS (Arquitetura de Design System escalável).

Infraestrutura: Vercel Edge Network com foco em latência zero.

2) LINGUAGEM DE MOVIMENTO (FLUIDEZ DE MARCA)
Mesmo sem o tom "Dark Moody", o site deve se mover com a precisão de um mecanismo suíço.

GSAP Orchestration: Animações baseadas em ScrollTrigger para guiar a narrativa do cliente.

Performance de Frame: Manter 60fps constantes. Proibido o uso de propriedades que causem Layout Shift ou Reflow desnecessário.

Interatividade Inteligente: Botões e inputs com feedback tátil e visual imediato. O site deve "responder" ao usuário de forma orgânica.

3) INTELIGÊNCIA E CONVERSÃO (O DIFERENCIAL JOESTAR)
Não entregamos apenas "páginas", entregamos ferramentas de venda inteligentes.

AI-Driven Features: Integração de agentes de qualificação (Chatbots de IA treinados) e funis de conversão dinâmicos.

Data-Driven Design: Implementação de eventos de rastreamento avançados (GTM/GA4/Pixels) nativamente na camada de servidor para evitar perda de dados.

Copy Estratégica: A estrutura deve priorizar a hierarquia de vendas: Gancho > Autoridade > Prova Social > Oferta > CTA.

4) ADAPTABILIDADE VISUAL (NEUTRALIDADE DE ELITE)
A marca do cliente é a estrela, mas a moldura é de luxo.

Design System Flexível: Cores e tipografia extraídas do Brandbook do cliente, mas aplicadas com regras de espaçamento e contraste de nível Apple/Stripe.

Fidelidade de Asset: Imagens e vídeos processados via Next/Image e Cloudinary para garantir nitidez máxima sem comprometer o tempo de resposta.

5) PROTOCOLO DE QUALIDADE (CHECKLIST DE ENTREGA)
Um projeto "Joestar" só é entregue se passar pelo crivo técnico:

[ ] WebVitals: Score Mobile estável acima de 90.

[ ] SEO Técnico: Estrutura de metadados, JSON-LD e semântica HTML impecáveis para dominar o Google.

[ ] Acessibilidade (a11y): Navegação clara, contrastes acessíveis e suporte a leitores de tela.

[ ] Segurança: Proteção de rotas, validação de inputs e headers de segurança configurados.

6) DIRETRIZ PARA O CURSOR (OPERATIONAL PROMPT)
Sempre que iniciar um projeto de cliente, use o seguinte comando:

"Cursor, estamos iniciando uma Operação de Cliente da Joestar Mídia. Utilize o @CLIENT_ENGINEERING_DIRECTORY.md. A estética deve seguir o manual de marca do cliente [Inserir Link/Doc], mas a engenharia deve ser Next.js 15, React 19 e GSAP de alta fidelidade. O objetivo é criar um site que exale robustez e inteligência técnica, consolidando nossa marca como provedora de soluções premium."
